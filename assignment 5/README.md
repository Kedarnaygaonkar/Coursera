# Paradise Nursery Shopping Application

## Project Name: Paradise Nursery

A dynamic e-commerce web application built with React and Redux for an online plant shop called **Paradise Nursery**.

## Description

Paradise Nursery is a fully functional shopping cart application that allows users to:
- Browse a wide variety of houseplants organized into categories
- View plant details including images, names, descriptions, and prices
- Add plants to a shopping cart
- Manage cart items (increase/decrease quantity, remove items)
- View the total cost of all items in the cart

## Technologies Used

- **React** (with Vite)
- **Redux Toolkit** for state management
- **React Router** for navigation
- **CSS** for styling

## Features

- 🌿 Browse 18+ unique houseplants across 3 categories
- 🛒 Dynamic shopping cart with real-time updates
- ➕➖ Quantity controls for each cart item
- 🗑️ Remove items from the cart
- 💰 Total cost calculation
- 📱 Responsive navigation bar
